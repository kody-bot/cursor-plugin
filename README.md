# Kody Cursor plugin

Cursor Marketplace plugin for [Kody](https://kody.codes). It ships a remote MCP connector at `https://kody.codes/mcp`.

This is a lean listing repo (manifest and MCP config only). Plugin format and submission follow the [Cursor plugins reference](https://cursor.com/docs/reference/plugins).

## Contents

- `.cursor-plugin/plugin.json` - plugin name `kody`
- `mcp.json` - remote MCP server at `https://kody.codes/mcp`

## Local test

Load this folder from `~/.cursor/plugins/local` as described in the [plugins reference](https://cursor.com/docs/reference/plugins), then connect Kody.

## Publish

Submit this repository at [cursor.com/marketplace/publish](https://cursor.com/marketplace/publish).
